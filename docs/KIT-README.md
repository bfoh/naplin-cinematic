# Hair By Naplin — Cinematic Edition starter resources

This is a **creative and implementation brief**, not a completed application. Paste `CODEX_MASTER_PROMPT.md` into Codex while its workspace is the NEW `naplin-cinematic` directory.

- `assets/reference/cinematic-art-direction.png`: generated **visual concept/mockup only**, not an implemented website or authentic business photography.
- `docs/CONTENT.md`: grounded editorial copy and approved business facts.
- `docs/DESIGN.md`: visual tokens and art direction.
- `docs/MEDIA.md`: provenance, asset manifest, and generation briefs.
- `docs/IMPLEMENTATION.md`: acceptance criteria and build sequence.

The original logo and authentic business photographs must be supplied/copied by the project owner; they are **not included** in this kit. All future generated imagery must be labeled as campaign/concept imagery, never as real customers, staff, students, or premises.
