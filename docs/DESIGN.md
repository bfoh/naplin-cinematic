# Cinematic design direction

Core premise: Hair is the art. Movement is the language. Confidence is the feeling.

Colors: ink #0A090B; oxblood #491721; burgundy #651F32; ivory #F0EAE1; champagne #C8A878; taupe #A69A90.
Typography: high-contrast Cormorant Garamond-style serif with expressive italic; Manrope-style restrained sans. Use locally managed font assets or Next font; avoid copying font files without license.

Art direction: premium Ghanaian/West African beauty editorial; believable glossy black hair; realistic skin texture; cinematic wine lighting; precise photographic crops; fine grain; ample negative space. Keep gold restrained. Do not blanket duotone skin and hair into flat gold.

Motion: GSAP/ScrollTrigger; Lenis desktop only if performant; one Three.js atmospheric hero canvas; subtle image masks and line reveals; optional desktop cursor. Mobile should be purpose-designed with reduced pins, native scrolling where beneficial, and minimal WebGL. Respect reduced motion.

Design rule: spectacle for storytelling, clarity for conversion. Shop/Book/Academy must remain discoverable.
